📁 Hướng dẫn cài đặt file .deb bằng Filza
  • 1 Bấm vào nút "Tải file .deb v2.4.0" ở trên bằng Safari trên iPhone.
  • 2 Sau khi tải xong, chọn Mở trong "Filza" (Open in Filza).
  • 3 Chạm vào file com.subdiox.storeswitcher2_2.4.0_iphoneos-arm64.deb trong Filza, chọn Cài đặt (Install) ở góc trên bên phải.
  • 4 Filza tự động chạy script postinst và thoát với mã Mã thoát: 0 (Success).
  • 5 Bấm Khởi động lại SpringBoard (Respring) là tweak và dylib đã kích hoạt hoàn tất!
