🔥 Tính năng nổi bật v2.3.0
  • AppAgent.dylib: Tiêm tự động vào app UIKit, giao tiếp IPC hai chiều tức thì với Tweak.
  • StoreKit / IAP Sandbox Sniffer: Bắt gói mua in-app, lấy Receipt Base64 và Replay giao dịch.
  • Deeplink & Scheme Hook: Bắt URL Scheme 2 chiều (Incoming / Outgoing) và ép mở URL từ xa.
  • Network API Hook: Bắt HTTP/HTTPS API, Request Body, Response Data và cho phép sửa / gửi lại.
  • Runtime Inspector: Quét Class, Methods, Properties và thực thi hàm Objective-C động.
  • UI Controller & Floating HUD: Bấm nút từ xa, nhập text, dump UI và bật cửa sổ nổi Sniffer trên màn hình app.
  • Terminal CLI (`agentcli`): Điều khiển toàn bộ tính năng qua dòng lệnh Terminal SSH/NewTerm.
  • Không lỗi phụ thuộc: Cấu hình dependencies tiêu chuẩn (firmware >= 11.0, mobilesubstrate/ellekit).
